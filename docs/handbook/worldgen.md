### <a id="world-terrain"></a>Terrain

Every world is generated from its seed: hills and plains by biome, caves below, seas up to the sea level. The same seed always gives the same world.

| | |
|---|---|
| Sea level | y 62 |
| Rock | [Stone](blocks.md#block-qtcraft-stone) |
| Seas and lakes | [Water](liquids.md#block-qtcraft-water) |
| Bottom | [Bedrock](blocks.md#block-qtcraft-bedrock) |
| Caves | yes |
