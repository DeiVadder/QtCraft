# QtCraft

A voxel sandbox game in the spirit of Minecraft, written from scratch in C++23 with Qt 6.8. Explore generated worlds with rivers, mountains and villages, mine and build, craft, farm and trade, wire up machines with Signal Dust, ride minecarts and survive the night – alone or with friends over an encrypted connection. Every texture, sound and piece of music is generated by the game itself, the content is plain JSON that mods can extend, and an in-game handbook documents every block, item and creature.

## Features

- **World:** generated terrain with 18 biomes, caves, ores, rivers and deltas, lakes; day and night, weather, fire, flowing water and lava. Also flat and void worlds and a showcase world with everything the game contains.
- **Survival:** mining, crafting, furnaces, hunger, farming and breeding, armour, bows, enchanting, maps, a backpack; game modes survival, creative, adventure and spectator.
- **Building and Signal Dust:** stairs, slabs, doors, signs, paintings; Signal Dust circuits (the game's own redstone-like wiring) with repeaters, comparators, pistons, hoppers; rails and minecarts.
- **Creatures and villages:** more than 25 kinds of creatures; villages with villagers, professions and trading; temples, mineshafts and dungeons.
- **Multiplayer:** a dedicated server or a world opened for the LAN, over TCP with TLS; chat, operators, whitelist, backups and an administration screen. Single player runs through the same protocol.
- **Modding and texture packs:** data-only mods (blocks, items, recipes, creatures, structures, sounds) and texture packs, including HD packs; the handbook includes mods.
- **More:** gamepad support, bindable keys, first- and third-person views, a character editor, English and German; `qtcraft-headless` for servers, bots and a JSON control interface.

## Download and run

**[Download the latest release](https://github.com/DeiVadder/QtCraft/releases/latest)** ([all releases](https://github.com/DeiVadder/QtCraft/releases)). The packages are built by GitHub Actions against open-source Qt 6.8.3.

- **macOS 13.3 or later** (Apple silicon and Intel, one universal app): `QtCraft-<version>-macOS.zip` or `.dmg`. The app is not notarised (it has no Apple developer signature), so macOS refuses the first start of a downloaded copy. Open it once anyway: on macOS 15 and later, try to open it, then go to **System Settings → Privacy & Security** and click **Open Anyway**; on macOS 13 and 14, right-click (Control-click) the app in Finder, choose **Open** and confirm. macOS remembers the choice. Details: [docs/Playing.md](docs/Playing.md#starting-the-game).
- **Windows 10 or 11, x64:** `QtCraft-<version>-Windows-x64.zip`. Unpack it completely and start `qtcraft.exe`; no installation. The program is not signed, so SmartScreen asks on the first start: **More info → Run anyway**.
- **Linux:** no package yet; building from source is untested.

Then create a new world and play: **H** opens the handbook, **E** the inventory, **Esc** the menu. Controls, settings and data folders: [docs/Playing.md](docs/Playing.md).

## Build from source

You need CMake 3.25+, Ninja, a C++23 compiler (Apple Clang or MSVC 2022), Qt 6.8 (Quick, QuickControls2, Multimedia, ShaderTools, LinguistTools, Test) Python 3, and `curl` and `perl` for OpenSSL; the first configure step builds SDL3 (gamepads) and OpenSSL (TLS) once.

```sh
git clone --recursive https://github.com/DeiVadder/QtCraft.git
cd QtCraft
cp CMakeUserPresets.example.json CMakeUserPresets.json   # then set your Qt and Ninja paths
cmake --preset release
cmake --build --preset release
```

Presets, Windows, the macOS bundle, tests and CI: [docs/Building.md](docs/Building.md).

## Status

QtCraft **0.1.0** is the first public release: playable and broad, but early. Expect rough edges; the [release notes](docs/release-notes/0.1.0.md) list what is known.

- **Worlds:** a world keeps the world generator version it was created with, and the game keeps generating new chunks for it exactly as that version did (on the same system; whether that holds across macOS versions is confirmed by the first CI runs). Version 1, shipped with 0.1.0, is frozen; later changes to the generator come as new versions, so old worlds get no seams where new terrain meets old. Worlds made with development builds before 0.1.0 may be refused.
- **Platforms:** macOS is the main platform (all tests run there). The Windows x64 package is built and checked by the release workflow, and Windows builds have been played and tested in a VM; the Windows tests in CI are still experimental. Linux builds in an experimental CI job only.

## About this project

I always wanted to build a Minecraft-like game, precisely because it lies outside my comfort zone and I wanted to learn how 3D rendering and all the rest of it work. AI made it possible: QtCraft is developed largely by AI coding agents, under my direction and review. I have to admit, though, that I didn't learn all that much about those things myself along the way :D
