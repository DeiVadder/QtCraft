### <a id="world-terrain"></a>Gelände

Jede Welt entsteht aus ihrem Seed: Hügel und Ebenen je nach Biom, darunter Höhlen, Meere bis zum Meeresspiegel. Derselbe Seed ergibt immer dieselbe Welt.

| | |
|---|---|
| Meeresspiegel | y 62 |
| Gestein | [Stein](blocks.md#block-qtcraft-stone) |
| Meere und Seen | [Wasser](liquids.md#block-qtcraft-water) |
| Grund | [Grundgestein](blocks.md#block-qtcraft-bedrock) |
| Höhlen | ja |

**Erzadern**

[Diamanterz-Vorkommen](#ore-qtcraft-diamond) (y 2–16), [Eisenerz-Vorkommen](#ore-qtcraft-iron) (y 5–64), [Erde-Vorkommen](#ore-qtcraft-dirt_pocket) (y 20–100), [Golderz-Vorkommen](#ore-qtcraft-gold) (y 5–32), [Kies-Vorkommen](#ore-qtcraft-gravel_pocket) (y 5–100), [Steinkohle-Vorkommen](#ore-qtcraft-coal) (y 5–128), [Ton-Vorkommen](#ore-qtcraft-clay_pocket) (y 40–70)

**Biome**

[Birkenwald](biomes.md#biome-qtcraft-birch_forest), [Ebene](biomes.md#biome-qtcraft-plains), [Gebirge](biomes.md#biome-qtcraft-mountains), [Sumpf](biomes.md#biome-qtcraft-swamp), [Taiga](biomes.md#biome-qtcraft-taiga), [Tundra](biomes.md#biome-qtcraft-tundra), [Wald](biomes.md#biome-qtcraft-forest), [Wüste](biomes.md#biome-qtcraft-desert)
