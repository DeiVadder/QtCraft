## QtCraft 0.1.0 – first public release

A voxel sandbox game in the spirit of Minecraft, written from scratch in C++23 with Qt 6.8. Everything you see and hear – textures, sounds, music – is generated by the game itself; the content is plain JSON that mods can extend. This is an early release: broad and playable, with rough edges.

### What's in it

- **World generation:** 18 biomes on a continuous climate map (with transition biomes such as snowy taiga and forest steppe), mountain ranges, caves, ores, winding rivers with deltas, lakes and rare lava lakes; villages, temples, mineshafts, dungeons, coastal towers. World types: normal, flat, void and a showcase world that shows everything the game and its mods contain. World options (biome size, caves, ore amount, villages …) are set per world.
- **Survival and creative:** mining, crafting, furnaces, hunger and food, farming and breeding, armour, bows, explosives, experience, enchanting and anvils, maps, a backpack, boats, beds; game modes survival, creative, adventure and spectator; game rules; advancements that guide a new player through the handbook.
- **Building and Signal Dust:** stairs, slabs, doors, fences, signs, frames and paintings; Signal Dust circuits with levers, buttons, repeaters, comparators, observers, pistons, dispensers and hoppers; rails and minecarts.
- **Creatures and villages:** more than 25 kinds of creatures, from farm animals and pets to monsters by night; villagers with professions, workplaces and trading.
- **Multiplayer:** a dedicated server (`qtcraft-headless --server`) or a world opened for the LAN, over TCP with TLS (the client pins the server's certificate on first contact); passwords, operators, whitelist, chat, backups and an administration screen. Single player uses the same protocol with a local server.
- **Modding and texture packs:** data-only mods (blocks, items, recipes, creatures, biomes, structures, villages, sounds, translations) and texture packs including HD packs and a realistic mode with material maps; the in-game handbook covers mods too.
- **Interface:** gamepad support, freely bindable keys, first- and third-person views, a character editor, interface scaling, English and German.
- **Tools:** `qtcraft-headless` runs servers and bots and offers a JSON control interface for scripts and agents.

Documentation: the [handbook](https://deivadder.github.io/QtCraft/handbook/) (also in the game with H or F1), the [API reference](https://deivadder.github.io/QtCraft/api/), and the [README](https://github.com/DeiVadder/QtCraft#readme) with the guides under `docs/` (playing, multiplayer and server hosting, modding, texture packs, control interface, building).

### Worlds and compatibility

- A world remembers the version of the world generator it was created with and keeps generating new chunks as that version did, on the same system. Generator version 1 ships with 0.1.0 and is frozen: later releases change the generator only through new versions, so 0.1.0 worlds keep their look where new terrain meets old.
- Worlds from development builds before 0.1.0 may be refused with a message.
- For multiplayer, client and server must speak the same protocol version; use the same release on both sides.

### Known limitations

- **macOS:** the app is not notarised. Open it the first time with right-click → Open (macOS 13 and 14), or allow it under System Settings → Privacy & Security → Open Anyway (macOS 15 and later).
- **Windows:** the program is not signed; SmartScreen asks on the first start (More info → Run anyway). The automated tests run on Windows only in a VM and in an experimental CI job; the package is checked by the release workflow (imported DLLs, a dedicated server with TLS and a bot that joins it), not by starting the game there.
- **Linux:** no package; Linux builds only in an experimental CI job.
- **Sound:** the generated sounds and music have not had a dedicated listening review yet; that follows after the first playtest.
- **API reference:** QDoc reference for the libraries `common`, `worldgen`, `network`, `audio`, `worlds` and `headless`; the server, client core, app and QML follow later.
- **Same world on the same system:** generated worlds are checked to be the same on the same system (the development Mac, and macOS in CI); between platforms (macOS versions, Windows, Linux, x86-64, ARM) details may differ by rounding.
- **Intel Macs:** the app is universal, but its Intel half has only been started under Rosetta on an Apple silicon Mac, never on a real Intel Mac.
- **Qt version:** the packages use open-source Qt 6.8.3; the game builds with any Qt 6.8 release.
